# 로컬 API 수집 및 V2 재학습

## 인증 및 자료

실제 인증키는 로컬 `.env`에만 보관합니다. `.env`, 원자료, 중복 모델,
후보/백업 모델 디렉터리는 Git 및 Docker 빌드 컨텍스트에서 제외합니다.
백엔드는 인증 URL이나 응답 본문을 오류 메시지에 포함하지 않습니다.
API Hub는 HTTPS와 `apihub.kma.go.kr`의 지원된 관측 경로만 허용합니다.

등록된 주소는 ZIP이 아닌 EUC-KR 텍스트 API입니다. URL에 들어 있는 예제
날짜와 지점은 실제 조회 날짜와 `KMA_STATION_ID`로 교체합니다.
시간자료는 오늘의 시각별 관측에, 일자료는 어제 확정 관측에 사용합니다.
최신 시각이 미공개라면 데이터를 만들어 표시하지 않습니다.

API Hub 일자료는 기존 44개 변수 전체를 제공하지 않습니다. 학습 자료는
기존 ASOS 일자료 API의 44개 구성을 유지합니다. 최근 예측 입력은 기존
ASOS 관측에 최신 API Hub 일자료를 병합하며, Hub에 없는 항목은 결측으로
유지하여 기존 전처리 경로로 전달합니다. 예측 입력 스냅샷에 최신 결측
필드가 기록됩니다. 시간자료로 모델을 재설계하는 것은 이번 학습에 포함되지 않습니다.

## 재학습 실행

프로젝트 폴더에서 PowerShell로 실행합니다.

```powershell
docker compose run --rm --no-deps -T -e PYTHONPATH=/app -v "${PWD}/backend/app:/app/app:ro" -v "${PWD}:/workspace" backend python -m app.train_v2
```

2000년 이후 일자료를 `data/local/daily`에 연도별 저장합니다. 완료된 과거
연도의 캐시는 재사용합니다. API Hub의 최신 일자료/시간자료도 로컬에
저장하지만, 인증키와 URL은 자료나 학습 메타데이터에 저장하지 않습니다.

기존 44개 기본 변수와 V2 파생변수, 결측 전처리를 재사용합니다.
목표값은 보간하지 않은 실제 이틀 뒤 평균기온입니다. 학습은 2022년,
검증은 2023–2024년, 평가는 2025년 이후를 사용하며 경계에 이틀 간격을
둡니다. 전처리 통계는 학습 구간에만 맞추고, 조기 종료와 앙상블 가중치는
검증 구간만 사용합니다. 테스트 구간으로 하이퍼파라미터를 조정하지 않습니다.

후보는 `artifacts/candidates`에 저장됩니다. 동일 테스트 구간에서 기존
V2와 단순 지속성 예측보다 MAE가 낮을 때만 교체 승인됩니다. 기존 모델은
백업 후 별도로 배포하며, 후보가 나쁘면 기존 모델을 유지합니다.

오늘 화면의 실제 날짜와 모델 입력 날짜는 다릅니다. 어제의 확정 일자료로
내일을 예측하므로 입력일 기준 t+2 모델을 사용합니다. 날짜가 맞지 않으면
내일 예측으로 저장하거나 표시하지 않습니다.

## 2026-10-06 실행 결과

로컬 후보 `ensemble-asos-daily-v2-local-20261006-005909`의 동일 테스트 구간
MAE는 2.182707°C, 기존 V2는 2.173582°C, 지속성 기준선은 2.705156°C였습니다.
후보가 기존 V2보다 좋지 않아 배포하지 않았습니다. 후보와 원자료는 로컬에
보존하고, 웹은 기존 검증 모델을 API Hub 최신 관측자료에 연결합니다.
최신 자료를 수집하거나 재학습했다는 사실만으로 성능 향상을 주장하지 않습니다.

## 웹 계산 근거 창

세 날씨 패널 아래에서 실제 예측의 입력 날짜/행 수, 기본 44개 변수의
원값·대체값, 주요 파생 입력값, CatBoost/LightGBM 예상 변화량과 가중합을
확인할 수 있습니다. 이 기록은 추론 시 함께 계산해 MySQL 입력 스냅샷에
저장하며, API 응답 `tomorrow.calculation`으로 전달합니다.

`model_evidence`에는 허용된 학습 기간/변수 수/점수만 전달하고 원본 config,
인증 URL, 인증키는 전달하지 않습니다. 학습 평가와 새 후보 비교 점수는
서로 다른 평가 구간일 수 있으므로 별도 표로 표시합니다. 변수 값은
SHAP 기여도나 인과 설명이 아니며 MAE는 개별 예측의 보장 오차가 아닙니다.

재학습 스크립트는 `artifacts/v2/training_audit.json`에 최근 평가 요약을
갱신합니다. Docker 백엔드를 재빌드해야 이미지 안의 새 평가 기록이 웹에
반영됩니다. 후보의 교체 조건 통과 여부와 실제 배포 모델 버전은 구분합니다.
